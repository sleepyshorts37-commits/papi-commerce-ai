# Mission 47 — Plan de travail (5 jours)

1. **Jour 1 — Contrat lecteur :** définir le mode lecture seule et les preuves de provenance attendues.
2. **Jour 2 — Adaptateur SQLite :** lire uniquement les lots commités et les références d'un reçu vérifié ; recalculer les empreintes.
3. **Jour 3 — Mémoire :** intégrer les mémoires partagées aux recherches avec contrôle d'accès, schéma et collisions.
4. **Jour 4 — PAPI CHAT :** intégrer les messages importés, validation du registre et filtrage destinataire.
5. **Jour 5 — Audit :** tests de corruption, collisions et compatibilité historique ; documentation et CI sur SHA final.

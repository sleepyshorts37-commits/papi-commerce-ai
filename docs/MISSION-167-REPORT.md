# Mission 167 — Verrou de publication sur la fiche KDP

## Livrable
- Le release gate exige désormais une fiche KDP complète validée par le module de mission 166.
- Compare titre, auteur, langue et description à la fiche éditoriale.
- Compare titulaire/preuve des droits et marketplace/devise/prix à leurs registres sources.
- Refuse catégories absentes, tranche d'âge invalide, stratégie ISBN non choisie ou prix incohérent.
- La fiche reste en revue propriétaire ; le statut maximal ne permet toujours que la soumission manuelle.

## Tests
- Fiche complète cohérente : prête à revue manuelle.
- Catégorie absente : bloquée.
- Prix divergent de la grille de prix vérifiée : bloqué.

# Mission 28 — Jour 2 : registre des workers

Le registre `papi_workers` conserve un identifiant technique et un identity_id uniques, la fonction, le département, le responsable hiérarchique, les compétences, les permissions, le statut et la capacité maximale. Les agents ne disposent d'aucun droit SQL direct. L'enregistrement ne les active jamais.

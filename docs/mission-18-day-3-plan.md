# Mission 18 — Jour 3/5 : vérification des preuves

## Livrables
1. Contrat d'observations documentaires structurées.
2. Validation des URL HTTPS, dates et présence d'un réviseur.
3. Détection des contradictions par champ.
4. Détection des preuves anciennes ou datées dans le futur.
5. Statut global conservateur, jamais de certification automatique.
6. Tests de régression et documentation des limites de confiance.

## Hors périmètre
Aucune consultation web automatique, aucune authentification de l'auteur d'une preuve, aucune validation définitive d'une plateforme et aucune candidature.

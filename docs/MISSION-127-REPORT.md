# Mission 127 — Générateur HTML de couverture complète

## Fonction
Compose une couverture complète à partir d'une image pleine largeur fournie, des dimensions exactes du gabarit KDP et de zones de texte explicites pour la face avant, la quatrième et éventuellement le dos. Le titre, sous-titre, résumé et auteur restent du texte éditable ; le nom d'auteur peut rester vide tant qu'il n'est pas confirmé.

## Limites
- Le module ne calcule pas la largeur du dos : il exige un gabarit KDP exact.
- Il ne génère pas l'illustration et ne produit pas un PDF final.
- Aucun faux ISBN, code-barres, logo, avis ou nom d'auteur n'est ajouté.
- Le résultat reste soumis au préflight PDF et à une validation humaine.
